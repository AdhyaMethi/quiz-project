# ⚡ QuizMaster - Django Quiz Application

A beginner-friendly, full-featured **Quiz Application** built with **Python, Django, MySQL, HTML, CSS, and JavaScript**.

---

## 🚀 Quick Start in VS Code

```powershell
# 1. Navigate into the application directory
cd quiz_application

# 2. Create virtual environment
python -m venv venv

# 3. Activate virtual environment
venv\Scripts\activate

# 4. Install dependencies
pip install -r requirements.txt

# 5. Run migrations
python manage.py makemigrations
python manage.py migrate

# 6. Load sample quiz data
python manage.py load_sample_data

# 7. Create admin superuser
python manage.py createsuperuser

# 8. Start development server
python manage.py runserver
```

Open in browser:
- **Student Portal**: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- **Teacher / Admin Portal**: [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)
